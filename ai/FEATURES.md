# lanclip — реализованный функционал

Формат: что сделано → ключевые решения → файлы.

## Windows: установка, права и автозапуск (`scripts/install-win.ps1`)

**Задача:** 25.

**Что сделано:** установочный PowerShell-скрипт, превращающий собранный
`lanclipd.exe` в постоянно работающую службу на ПК Павла — сборка через
`win/build.ps1`, установка бинарника в `%USERPROFILE%\.local\bin\lanclipd.exe`,
создание конфига (только если его ещё нет — существующий токен не трогается),
`netsh http add urlacl` для `http://+:8901/`, правило файрвола на входящий TCP
8901 и задача планировщика с триггером входа в систему в интерактивной сессии
пользователя.

**Ключевые решения:**
- Пользователь для urlacl/задачи берётся из
  `[Security.Principal.WindowsIdentity]::GetCurrent().Name`, а не из
  `$env:USERDOMAIN` — на этой машине последний возвращает "WORKGROUP", а не имя
  компьютера.
- Триггер задачи — `-AtLogOn` с `-LogonType Interactive`: агенту нужен
  настоящий системный буфер обмена и трей-иконка, которые существуют только в
  оконной станции WinSta0 интерактивного рабочего стола (см. `ai/ERRORS.md`).
- `ExecutionTimeLimit` задачи явно снят в ноль — дефолтные 72 часа Task
  Scheduler молча убили бы резидентный процесс через трое суток работы.
- Action задачи запускает не сам `lanclipd.exe` (консольное приложение), а
  скрытую обёртку `powershell.exe -WindowStyle Hidden` — дочерний консольный
  процесс наследует уже скрытую консоль вместо того, чтобы открыть свою.
- Правило файрвола — `-Profile Any`, а не `-Profile Private` из исходного
  брифа: реальный сетевой адаптер этой машины классифицирован Windows как
  Public, и ограничение Private не пропустило бы трафик с Mac (см.
  `.superpowers/sdd/2026-08-18-lanclip/task-25-report.md`).
- Идемпотентность: конфиг не перезаписывается, если уже существует; urlacl и
  правило файрвола пересоздаются только если принадлежат нам самим (иначе —
  явная ошибка, а не тихая перезапись чужого); задача планировщика снимается
  и создаётся заново.
- Доставка на ПК — тем же механизмом, что и остальной Windows-код
  (`scripts/sync-win.sh`), без отдельного канала.

**Файлы:** `scripts/install-win.ps1`, `scripts/sync-win.sh`.
